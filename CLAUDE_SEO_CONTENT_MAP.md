## Cross-cutting SEO recommendations (not domain/canonical changes)

1. **Sitemap/RSS scope:** per the red-team report, none of the 11 URLs above are currently in `sitemap.xml` or `feed.xml`. This map assumes Codex will decide, deliberately, whether to widen `publicRoutes` (`src/pages/sitemap.xml.ts`) and the RSS entry list (`src/pages/feed.xml.ts`) once each piece has real content — not before, to avoid inviting crawlers to one-paragraph stubs.
2. **Internal linking is currently thin between desks.** Cards link within their own desk (research → research) but rarely across desks. The "related pages" column above is a concrete, ready-to-implement cross-linking plan once each piece exists.
3. **Schema types are placeholders for pre-production status.** Do not mark anything `VideoObject`/`Article` with a real `datePublished` until the piece is actually published — doing so before real publication would be exactly the kind of overclaiming the site's own editorial principles reject.
4. **Category/tag taxonomy above is new** (the current data model has no `tags` field — see `EditorialItem` type in `src/data/content.ts`). Adding tags is a schema change for Codex to implement, not something this review modifies.
