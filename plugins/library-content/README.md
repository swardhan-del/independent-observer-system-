# Library content blocks

This plugin supplies the public library's four-volume content blocks. Each block connects a
roadmap volume to a short public-safe summary, core ideas, topic lenses, and matching
preprint reading copies.

The public taxonomy connects reviewed research families to available reading records. Selected author working papers also have full-text reading editions in manuscripts.generated.json, with explicit source versions and working-paper status. Private archive paths, supporting records, and unselected revisions remain outside the public plugin. Catalogue usage figures remain descriptive signals, not ratings.

The component is dependency-free and progressively enhanced. Without JavaScript, all four blocks
and their links remain visible; JavaScript only adds the local volume filter and URL state.

Full-text editions use /library/manuscripts/ routes and remain linked to their taxonomy families. Historical platform mentions inside author prose are preserved; they do not create outbound platform links or change the existing catalogue migration.
