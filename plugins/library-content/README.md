# Library content blocks

This plugin supplies the public library's four-volume content blocks. Each block connects a
roadmap volume to a short public-safe summary, core ideas, topic lenses, and matching SSRN
preprint reading copies.

The plugin does not copy Dropbox manuscripts, expose private archive counts beyond the reviewed
aggregate snapshot, or mark any candidate as an Independent Observer publication. SSRN records
remain labeled as preprints and their usage figures are descriptive signals, not ratings.

The component is dependency-free and progressively enhanced. Without JavaScript, all four blocks
and their links remain visible; JavaScript only adds the local volume filter and URL state.
