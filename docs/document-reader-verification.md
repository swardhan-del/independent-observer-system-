# Author-paper reader verification

Inspection date: 31 August 2026

The canonical public-safe catalogue is `src/data/papers.ts`; the rendered routes are generated by
`src/pages/library/documents/[slug].astro`.

The current branch verifies the following boundary:

- 21 neutral author-paper routes render source-reviewed synopses and selected analytical points.
- 18 routes link to exact, title-matched ResearchGate records.
- 3 routes publish no outbound paper-platform link because an exact, content-consistent record was
  not verified.
- Every route displays a source fingerprint, archive-placement note, working-paper status, rights
  notice, and dated historical distribution counts.
- Prior route slugs permanently redirect to the neutral routes.
- The `public/` tree contains no paper PDF, paper DOCX, or complete manuscript HTML.
- Private Dropbox paths and files are not present in the generated site.

The full source taxonomy, exceptions, and release boundary are recorded in
`docs/author-paper-migration-audit-2026-08-31.md`.

This verification does not authorize full-text publication, a peer-review claim, merge, or
production promotion.
