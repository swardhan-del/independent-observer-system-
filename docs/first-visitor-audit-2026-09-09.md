## Boundaries

Existing scholarly titles, original manuscript release status, sources and review claims are retained. The invented-number example is teaching material, not empirical evidence. Existing public summaries remain available. This change does not release the six essays or any private manuscript.

The visual review found a coherent navy-and-gold palette and readable mobile typography. The changes focus on orientation and the first reading experience, not a wholesale redesign.

## Acceptance checks

- A newcomer can identify the author and purpose from the homepage.
- Start Here offers a single direct first read before broader journeys.
- The worked example explicitly labels every number as invented.
- Optional homepage controls remain operable and do not precede the introduction.
- Unreleased work remains labeled as in development.
- Existing build, publication-boundary, desktop/mobile journey and production-contract checks must pass before reporting the release as verified.
